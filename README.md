# آموزش ریاضیات ۱

برنامهٔ وب فارسی و راست‌چین برای تمرین حساب ریاضی کودکان. این نسخه روی مرورگر کار می‌کند و نیازی به نصب یا اینترنت برای بازی و ثبت نمره ندارد (برای فونت آنلاین و ویدیوها اینترنت لازم است).

## اجرا

1. فایل ZIP مخزن را از GitHub دریافت کنید یا مخزن را دانلود کنید.
2. `index.html` را با مرورگر باز کنید.
3. نام شاگرد را وارد کنید، درس را انتخاب کنید و وارد بازی، کاربرگ یا ویدیو شوید.

همچنین می‌توان از مخزن، GitHub Pages را فعال کرد تا برنامه با یک پیوند اینترنتی در دسترس باشد: **Settings → Pages → Deploy from a branch → main / (root)**.

## امکانات نسخهٔ نخست

- ۲۱ عنوان مقدماتی حساب ریاضی، همراه با توضیح و مثال.
- بازی ۳۰ پرسشی برای هر عنوان، تولید پرسش و ثبت نمره.
- ذخیرهٔ نام، نمره‌ها و مجموعه پرسش‌ها در `localStorage` مرورگر روی همان دستگاه.
- کاربرگ چاپی A4 شامل همان ۳۰ پرسش بازی.
- پیوند جست‌وجوی یوتیوب برای یافتن درس از شبکهٔ تمدن؛ پیوند مستقیم هر ویدیو باید پس از بررسی انتخاب و جایگزین شود.
- راست‌چین و سازگار با صفحهٔ موبایل و کمپیوتر.

## نکتهٔ ذخیره‌سازی

اطلاعات فقط در مرورگر و دستگاه فعلی می‌ماند. پاک‌کردن داده‌های مرورگر یا استفاده از مرورگر/کامپیوتر دیگر ممکن است باعث از دست رفتن نمره‌ها شود. این نسخه هنوز ورود شاگرد، همگام‌سازی ابری یا خروجی پشتیبان ندارد.

## ادامهٔ توسعه

برای نسخهٔ بعدی می‌توان پشتیبان‌گیری و بازیابی نمره‌ها، مدیریت چند شاگرد، شنیدن پرسش‌ها، ویدیوهای مستقیم تأییدشده و محتوای کامل‌تر آموزشی را افزود.
